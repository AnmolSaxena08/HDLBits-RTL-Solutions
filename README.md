# HDLBits RTL Solutions

A curated collection of my solutions for the HDLBits Verilog problem set.
This repository contains RTL-level Verilog implementations covering combinational logic, sequential circuits, FSMs, counters, shift registers, arithmetic circuits, and more.

## 🚀 About HDLBits

[HDLBits](https://hdlbits.01xz.net/wiki/Main_Page?utm_source=chatgpt.com) is an interactive platform for practicing digital design using Verilog HDL.
It is widely used for strengthening concepts in:

* Digital Logic Design
* RTL Coding
* Finite State Machines (FSM)
* Sequential & Combinational Circuits
* Timing & Simulation Concepts
